v2026-08
================================
- all scripts consolidated to harvest_restrictions.py

- existing harvest_restrictions.py CLI commands renamed, commands are now:

  cache        Download sources defined in provided sources.json file
  clear-cache  Delete cached parquet files written by cache (hr_*.parquet)
  load-db      Load source layers from parquet cache to the postgresql db
  overlay      Run per-tile overlay and write output and rollup/summaries...
  release      Publish a dated release from the current commit's...

- object storage files reorganized (#26, #27, #28), new structure is:

  s3://$BUCKET/harvest_restrictions/
    ├── cache/                                        # cached download of source layers as untagged geoparquet)
    │   ├── hr_01_park_national.parquet
    │   ├── hr_02_park_er.parquet
    │   ├── hr_03_park_provincial.parquet
    │   └── ...
    │
    ├── draft/                                        # outputs for review on completion of overlay (tagged commit/run_id, overwritten each run)
    │   ├── harvest_restrictions.parquet
    │   ├── harvest_restrictions_sources.parquet
    │   ├── land_designations_summary.csv
    │   ├── harvest_restrictions_summary.csv
    │   └── sources.csv
    │
    ├── LOG_land_designations.csv                     # durable change log (append-only, all past releases)
    ├── LOG_harvest_restrictions.csv
    │
    ├── harvest_restrictions.gpkg                     # latest-release pointers (plain names, root)
    ├── harvest_restrictions_sources.gpkg
    ├── land_designations_summary.csv
    ├── harvest_restrictions_summary.csv
    ├── sources.csv
    │
    └── releases/                                     # permanent per-release archive (never overwritten)
        ├── harvest_restrictions_v2024-08.gpkg
        ├── harvest_restrictions_v2025-04.gpkg
        ├── harvest_restrictions_v2025-08.gpkg
        ├── harvest_restrictions_v2026-02.gpkg
        └── harvest_restrictions_v2026-08.gpkg        # each bundles 5 tables (see below)

    Each releases/harvest_restrictions_<tag>.gpkg internally holds:
    harvest_restrictions_v2026-08.gpkg
    ├── harvest_restrictions          (spatial layer)
    ├── designations                  (spatial layer)
    ├── land_designations_summary     (non-spatial table)
    ├── harvest_restrictions_summary  (non-spatial table)
    └── sources                       (non-spatial table)

- release workflow added, releases are autogenerated when a tag is pushed to github
