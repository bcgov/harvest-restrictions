v2026-08
================================
- all scripts consolidated to harvest_restrictions.py

- existing harvest_restrictions.py CLI commands renamed, commands are now:

  cache              Download sources defined in provided sources.json file
  clear-cache        Delete cached parquet files written by cache (hr_*.parquet)
  load-db            Load source layers from parquet cache to the postgresql db
  overlay            Run per-tile overlay, writing the results to the database and drafts/
  prerelease         Publish the overlay draft in drafts/ as a release candidate
  release            Release the checked-out commit's release candidate

- releases are made in two steps:
  - release candidate: tag a commit <version>-rc.<n>, run `overlay` on it (writing the draft to
    drafts/, with overlay_run.json recording the commit and any uncommitted changes), then
    `prerelease` publishes the draft for review (only if it was run on the tagged commit, with
    no uncommitted changes other than to documentation)
  - release: tag the approved candidate's commit <version> and push the tag - the release
    workflow (requiring approval) promotes the candidate as is, then deletes the version's
    release candidates

- in support of change tracking/reporting:
  - overlapping data are always sorted by index, primary_key, name
    (previously the sort was only by index, the key/name retained in cases of same-source overlaps
    was random)
  - output `_all_*` columns are now JSON arrays instead of ; separated strings
    (this supports ';' in the source's name, and retains all values rather than dropping nulls)

- object storage files reorganized, new structure is:

  s3://$BUCKET/harvest_restrictions/
  ├── cache/                                    # per-source geoparquet cache, written by `cache`
  │   ├── hr_01_park_national.parquet
  │   ├── hr_02_park_er.parquet
  │   └── ...
  ├── sources/                                  # sources not available for download elsewhere,
  │   ├── CRD.gdb.zip                           #   in their native format - referenced by sources.json
  │   └── ...
  ├── drafts/                                   # release candidates (published drafts), written by `prerelease`
  │   └── harvest_restrictions_<version>-rc.<n>.zip   # as releases/, never overwritten
  ├── latest/                                   # the latest release's files, written by `release`
  │   ├── harvest_restrictions.gpkg
  │   ├── harvest_restrictions_sources.gpkg
  │   ├── land_designations_summary.csv
  │   ├── harvest_restrictions_summary.csv
  │   └── sources.csv
  ├── logs/                                     # change logs, appended to by `release`
  │   ├── land_designations.csv
  │   └── harvest_restrictions.csv
  └── releases/                                 # permanent per-release archives, written by `release`
      └── harvest_restrictions_<release_tag>.zip
          ├── harvest_restrictions.gpkg         (harvest_restrictions layer)
          ├── harvest_restrictions_sources.gpkg (designations layer)
          ├── land_designations_summary.csv
          ├── harvest_restrictions_summary.csv
          └── sources.csv
